# Día 1 — Generador de nombres para bandas

## Descripción

Programa sencillo que solicita al usuario el nombre de una ciudad y el nombre de una mascota para generar una posible combinación como nombre de banda.

## Conceptos practicados

- `print()`
- `input()`
- Variables
- Cadenas de texto
- F-strings

## Cómo ejecutarlo

Desde la terminal, dentro de la carpeta principal:

```bash
python day-001-band-name-generator/main.py
```

En Windows también puedo utilizar:

```bash
py day-001-band-name-generator/main.py
```

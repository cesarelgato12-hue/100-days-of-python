# Día 4 — Piedra,papel o tijera

## Descripción

crear un programa del juego clasico piedra, papel o tijera para competir contra el computador

## Conceptos practicados
```
random_number_0_to_1 = random.random()
print(random_number_0_to_1)

0.50344
05555656  
05556777
```
.append("") -> sirve para añadir a la lista después de ya estar escrita.

.remove("") -> sirve para quitar de la lista después de ya estar escrita.


## Cómo ejecutarlo

Desde la terminal, dentro de la carpeta principal:

```bash
python  starter/100-days-of-python/day 004 - piedra-papel-tijera/main.py"
```

En Windows también puedo utilizar:

```bash
py  starter/100-days-of-python/day 004 - piedra-papel-tijera/main.py"
```

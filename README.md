# 🐍 100 Days of Code: Python

Este repositorio documenta mi progreso en el curso **100 Days of Code – The Complete Python Pro Bootcamp**.

Mi objetivo es aprender Python mediante la práctica constante, desarrollar proyectos y construir un portafolio que muestre mi evolución.


## 📂 Organización

Cada carpeta diaria puede contener:

- El código desarrollado.
- Un archivo `README.md` con lo aprendido.
- Las dificultades encontradas.
- Las mejoras realizadas por mi cuenta.

## 🎯 Objetivos

- Aprender los fundamentos de Python.
- Practicar programación de forma constante.
- Mejorar mi capacidad para resolver problemas.
- Aprender Git y GitHub.
- Construir proyectos para mi portafolio.

## 🛠️ Herramientas

- Python
- Visual Studio Code
- Git
- GitHub

## ⚠️ Aviso

Este repositorio contiene únicamente código, apuntes y proyectos elaborados como parte de mi proceso personal de aprendizaje. No incluye videos, documentos, soluciones oficiales ni materiales privados del curso.

# Apuntes de Python

## Función `print()`

Se utiliza para mostrar información en pantalla.

```python
print("Hola, mundo")
```

## Función `input()`

Permite recibir información escrita por el usuario.

```python
nombre = input("¿Cómo te llamas? ")
```

## Variables

Una variable sirve para guardar un valor.

```python
edad = 20
nombre = "Ana"
```

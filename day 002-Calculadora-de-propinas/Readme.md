# Día 2 — Generador de nombres para bandas

## Descripción

calculadora de propinas, donde de la factura que se tiene que pagar se pregunta cuanto de propina se tiene que dar.

## Conceptos practicados

- print(Hello[0]) = H -> sirve para indicar la posición exacta de la palabra.
- print(type(123)) = <class int> -> nos indica que tipo de datos se esta utilizando.

## Cómo ejecutarlo

Desde la terminal, dentro de la carpeta principal:

```bash
python  002-Calculadora-de-propinas/main.py
```

En Windows también puedo utilizar:

```bash
py  002-Calculadora-de-propinas/main.py
```

## Reflexión personal

en la programación se cuenta a partir del 0 en adelante. 

otra forma de poder sumar es: print(int("123)+ int("456")) = 579 

Para dividir es mejor utilizar // doble ya que con uno solo sale float. pero en cuestión de resultados exactos, si requiere inexacto es mejor utlizar /. 

en algunas ocasiones para reducir el proceso se puede hacer el String -f : print(f"my name is {name}").
